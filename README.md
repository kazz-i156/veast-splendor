# VEAST Splendor（ヴィースト・スプレンダー）

ロボットが主役の横スクロールシューティングゲーム。
`index.html` ひとつで動き、インストール不要。スマホ（横向き推奨）とPCブラウザの両方に対応しています。

## 遊び方

`index.html` をブラウザで開くだけで遊べます。GitHub Pages を有効にすると、URLからスマホで直接遊べます。

| 操作 | スマホ | PC |
|---|---|---|
| 移動 | 画面をドラッグ（指の位置は自由） | 矢印キー / WASD |
| ショット | 自動連射 | 自動連射 |
| バースト（弾消し＋全体攻撃） | 右下の BURST ボタン | X / Shift |
| 低速移動 | — | C |
| 一時停止 | 右上の II ボタン | P / Esc |
| 消音 | — | M |

## ゲーム内容（試作版 v0.1）

- 自機：V字アンテナの人型ロボット。当たり判定は胸の白いコアだけ
- 敵：ドローン（編隊）、ガンナー（狙い撃ち）、ヘビー（扇状弾・Pアイテム確定ドロップ）
- アイテム：**P** でショット強化（最大Lv3）、**H** で装甲回復
- バーストゲージ：敵を倒すとたまり、満タンで発動可能
- 約80秒でボス「GRAND VEAST」が出現。倒すと難易度が上がった次のループへ
- ハイスコアはブラウザに保存されます

## 技術メモ

- HTML5 Canvas と素のJavaScriptのみ（外部ライブラリなし・画像なし）
- 効果音は WebAudio で生成
- 論理解像度は 960×540。画面サイズに合わせて拡大縮小します
