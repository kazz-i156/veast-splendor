# VEAST Splendor（ヴィースト・スプレンダー）

ロボットが主役の横スクロールシューティングゲーム。
`index.html` ひとつで動き、インストール不要。スマホ（横向き推奨）とPCブラウザの両方に対応しています。

## 遊び方

`index.html` をブラウザで開くだけで遊べます。GitHub Pages を有効にすると、URLからスマホで直接遊べます。

| 操作 | スマホ | PC |
|---|---|---|
| 移動 | 画面をドラッグ（指の位置は自由） | 矢印キー / WASD |
| ショット | 自動連射 | 自動連射 |
| バースト（弾消し＋全体攻撃） | 右下の BURST ボタン | X / Shift |
| 低速移動 | — | C |
| メニュー選択（タイトル） | START / OPTION をタップ | ←→ で選択・Enter で決定 |
| 一時停止 | 右上の II ボタン | P / Esc |
| 消音 | — | M |

## ゲーム内容（試作版 v0.1）

- 自機：V字アンテナの人型ロボット。当たり判定は胸の白いコアだけ
- 自機には緩い重力がかかり、上下の操作をしていない間はゆっくり沈んでいく
- 敵：ドローン（編隊）、ガンナー（狙い撃ち）、ヘビー（扇状弾・Pアイテム確定ドロップ）
- アイテム：**P** でショット強化（最大Lv3）、**H** で装甲回復
- バーストゲージ：敵を倒すとたまり、満タンで発動可能
- 約80秒でボス「GRAND VEAST」が出現。倒すと難易度が上がった次のステージへ
- ステージ構成：1面＝夜の都市、2面＝昼の森林、3面＝昼の砂漠。4面以降はこの3つを繰り返す
- タイトルの **OPTION** で開始ステージ（1〜3）を選べる。選んだステージはブラウザに保存され、タイトル背景もそのステージになる
- ハイスコアはブラウザに保存されます

## 技術メモ

- HTML5 Canvas と素のJavaScriptのみ（外部ライブラリなし・画像なし）
- favicon（V字アンテナのロボット頭部）は index.html に埋め込み済み。元データは `favicon.svg`、iOSホーム画面用は `apple-touch-icon.png`
- 効果音・BGMは WebAudio でその場で合成（音声ファイルなし）
- BGMはオリジナル曲：道中「Steel Horizon」（Aマイナー・148BPM）、ボス「Grand Veast」（Eフリジアン・168BPM）、ほかタイトル／クリア／ゲームオーバー
- 論理解像度は 960×540。画面サイズに合わせて拡大縮小します
